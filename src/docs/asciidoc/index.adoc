== Expected Behavior

After this file is saved, the generated HTML changes and the browser page should update to show the latest content.

== What This Project Checks

The live reload script checks for changes by using the `HEAD` response.

With the affected plugin implementation, the `HEAD` response is `205 Reset Content` with `content-length: 0`, so the browser-side script cannot detect that the generated HTML changed.
